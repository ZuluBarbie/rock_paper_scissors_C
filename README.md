# Rock Paper Scissors in C

A command-line Rock Paper Scissors game written in C.

The player competes against the computer in a first-to-3 match.

## Features

- Rock, Paper and Scissors choices
- Random computer opponent
- Score tracking
- First-to-3 game mode
- Input validation
- Displays choices as words
- Announces the overall winner

## Built With

- C
- GCC
- Visual Studio Code

## How to Run

Compile the program:

```bash
gcc main.c -o rps.exe
